# Qualify and prepare the 1.1.0 release

## Outcome

The repository is ready for a 1.1.0 release with coherent metadata, release notes, packages, and bounded real-harness evidence.

## Context

This area contains additive post-1.0 improvements, so prepare the next minor release as 1.1.0. Existing automated release smoke proves generated bytes and binary flows but not real harness execution; add a concise manual qualification record rather than a provider-backed CI matrix.

## Boundaries

- Update version metadata and generated integration manifests through their canonical sources.
- Add a useful changelog summary of user-visible behavior and migration notes.
- Run bounded manual ready/PASS, REWORK, verify-only, closed no-work, goal/loop, and small-audit smoke on supported harnesses available to the maintainer; record unavailable harnesses honestly.
- Do not add paid provider CI, statistical evaluations, publish artifacts, push, or create the release tag in this task.
- Do not expand scope to fix unrelated issues discovered during qualification; add or propose focused tasks instead.

## Done when

- [ ] Cargo, lockfile, package, and all integration manifests consistently report 1.1.0.
- [ ] CHANGELOG documents the improvements and any compatibility considerations since 1.0.0.
- [ ] Clean source and package builds, all automated checks, five-harness install/check, generated-artifact equality, representative binary round trips, and distribution planning pass.
- [ ] A concise qualification record shows actual harness versions and outcomes for the bounded scenarios, including any unavailable coverage.
- [ ] The final diff and Git state are suitable for a maintainer release commit and later v1.1.0 tag.

## Validation

- Run fmt, strict locked clippy, full locked tests, clean locked source/build/package verification, release smoke, five-harness install/check, generated-artifact equality, representative binary round trips, distribution sync/plan, and git diff checks.
- Run and record the bounded manual harness matrix described in the task.
- Inspect packaged file inventory and rendered version fields.
