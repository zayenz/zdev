# Notes for future work

Keep unfinished plans, future ideas, open questions, and collected research
here. Use a descriptive filename for a single note or a topic folder for
related documents. Nested folders are welcome. A folder README is optional;
there is no required template, metadata, status, or index.

The zdev skill supports **add note**, **list notes**, and **make area from
note**, for both files and folders. Notes stay outside the task queue.

See [Notes for future work](../../docs/user-guide.md#keep-notes-for-future-work)
for examples and how to turn a note into an area.
